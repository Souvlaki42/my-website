# My Website

This is where I store my personal portfolio, my own space on the internet.
Here I share my opinions and experience, showcase my work and highlight my abilities.
Hope it may be useful to you in some way, or that some recruiter will learn about me through it.

## Getting Started

Follow these instructions to set up the project locally.

### Prerequisites

Ensure you have the following installed:

- [Node.js](https://nodejs.org/en) (v24 or later)
- [Pnpm](https://pnpm.io/) (v12 or later)

### Installation

1. **Clone the repository**

   ```sh
   git clone git@github.com:Souvlaki42/my-website.git
   ```

2. **Navigate to the project directory**

   ```sh
   cd my-website
   ```

3. **Install dependencies**

   ```sh
   pnpm install
   ```

4. **Start the development server**

   ```sh
   pnpm dev
   ```

5. **Open the project in your browser**

   Navigate to `http://localhost:4321` to view the portfolio.
