I have successfully decompiled Pony Island into a working modern Unity project. It took a day of work but I managed to do so.

I did it on the Linux native version but it should work on other platforms too.

I recently stumbled upon the idea of game decompilation and I wanted to try it. Specifically, the version for Unity games.

I chose that game specifically because it is an old indie game with a Linux version, so unlikely to obfuscate and what not. However, this process, albeit slightly different should work on other games too.

I also really love this game and I own a legal copy of it which is required to do this. I got my own on Steam.

Used the free version of [Asset Ripper](https://github.com/AssetRipper/AssetRipper) v2.0.0 to get most of the job done. Rest, was just upgrades and bug fixing.

In the process of doing so, I ended up migrating the project to the newest Unity version. Not a 100% perfect upgrade though.

From its original Unity 2017.4.40f1 LTS to Unity 6000.3.26f1 LTS.

## Process

Firstly, the project comes with deprecated Unity's In-App Purchases 4, which isn't used so I just removed it.

After that, I removed every `AssemblyInfo.cs` file I could found.

Then, I hit enumerator errors from legacy Unity script and Boo Language in `CharacterMotor.cs`.

I fixed them, by replacing `SubtractNewPlatformVelocity` method with a modern equivalent written by AI:
```cs
private IEnumerator SubtractNewPlatformVelocity()
{
    if (movingPlatform.enabled &&
        (movingPlatform.movementTransfer == MovementTransferOnJump.InitTransfer ||
         movingPlatform.movementTransfer == MovementTransferOnJump.PermaTransfer))
    {
        if (movingPlatform.newPlatform)
        {
            Transform platform = movingPlatform.activePlatform;

            yield return new WaitForFixedUpdate();
            yield return new WaitForFixedUpdate();

            if (grounded && platform == movingPlatform.activePlatform)
                yield return 1;
        }

        movement.velocity -= movingPlatform.platformVelocity;
    }
}
```

And then, removed `using Boo.Lang;` and the entire `_0024SubtractNewPlatformVelocity_00241` subclass.

Later, in `GameOverText.cs`, I changed references of legacy `GUIText` to `Text` after adding `using UnityEngine.UI;` on the top of the file.

Added, `steam_appid.txt` in the root of project outside `Assets/` directory, containing text `405640`, the game's appid on Steam.

Replaced, game's old `Steamworks/` wrapper directory with latest [Steamworks.NET](https://github.com/rlabrecque/Steamworks.NET) using their [instructions](https://steamworks.github.io/installation/#unity-instructions).

In `AchievementManager.cs`, I removed the `SteamUserStats.RequestCurrentStats()`  method call as [it became obsolete](https://wiki.facepunch.com/steamworks/SteamUserStats.RequestCurrentStats) and just manually set `m_bRequestedStats` to true on the `Initialize()` method.

Lastly, I was able to replace most of the dummy shader stubs generated by free Asset Ripper with the equivalents from `Unity's Standard Assets Package`, specifically an archive of the image effect part of it, as found in this [Dropbox re-upload by reddit user TyroByte](https://www.reddit.com/r/Unity3D/comments/jacohw/where_can_i_download_the_image_effects_standard/).
